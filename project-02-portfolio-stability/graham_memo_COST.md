# Graham-style memo: COST

## Verdict: watch it

Net income is positive in every reported year and grew from 5,844 to 9,226, so both earnings screens pass. The balance-sheet screen fails because the latest current ratio is 1.06, below the stated 2 threshold.

The results show earnings stability but not the conservative short-term liquidity margin required by this screen. I would watch the business rather than call it a Graham-style pass on these facts alone; this is not a conclusion about price.

## Threshold decision

I keep the 2 current-ratio threshold because it preserves Graham’s conservative liquidity margin; the lower threshold probe would make COST pass but weakens that design choice.
