# Repository Guidance

This repository supports FIN 43900 coursework for Fall 2026.

## Finance coursework support

- Treat finance questions as collaborative learning: explain concepts, show the source or calculation, and help the student verify their own work.
- For SEC-filing assignments, use the filing specified by the student; if the assignment requires the current filing, verify it is the newest applicable 10-K or 10-Q.
- Preserve clear evidence for filing accession number, reporting period, filing date, currency, units, cash, debt, diluted-share count, and operating drivers.

## Working conventions

- KISS: keep it simple and stupid.
- Keep changes focused on the requested assignment or task.
- Preserve existing files and student work unless explicitly asked to replace them.
- Use clear filenames and concise documentation for any new deliverables.
- Verify calculations, formulas, and financial assumptions before presenting results.
- Do not submit work, send messages, or access external services without explicit authorization.

## Before finishing

- Review changed files for accuracy and formatting.
- State what was created or changed and note any assumptions.
