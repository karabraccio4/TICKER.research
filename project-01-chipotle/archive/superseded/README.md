# Superseded Working Files

These files are preserved for project history only. They are not part of the
final runnable valuation application and should not be used to support the
final recommendation.

## Why these files are archived

- `reports/Project_1_Company_Research_Report_Chipotle.md` contains unsourced
  working material and an obsolete December 31, 2025 valuation date.
- `reports/Project_1_Edition_A_Chipotle.md` and
  `reports/Project_1_Edition_A_Chipotle_DRAFT.md` are later working drafts;
  they are not the unchanged Edition A checkpoint.
- `models/dcf.py` and `models/proforma.py` are standalone legacy models. They
  are superseded by the integrated `models/cmg_proforma.py` and
  `models/cmg_integrated_dcf.py` models.
